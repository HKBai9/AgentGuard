# 第一阶段基础修复（1.1.1）

本阶段修复当前实现的已知错误，不包含新网关、模型诊断或安全续行功能。
验证使用固定输入、模拟结果及本机临时 HTTP 服务；不调用大模型、不运行对照实验。

## 修复内容

1. **检查与执行共享输入。** `ActionView` 保存全部网络目标、文件读取路径及解析后的 argv。
   网络目标逐个校验，任何目标越权则不下发整条调用。SDK 补齐默认参数、验证完整签名，
   按同一份绑定参数执行；无法确定资源的调用拒绝执行。
2. **明确命令语法。** 内置适配器支持受限 curl HTTP(S) 探测、cat 文件读取、ls 沙箱目录，
   以及 echo/whoami/uname。curl 支持多个 URL、`--url URL`、常用探测标志与至多 25 秒超时；
   配置文件、代理、重定向、URL 展开、文件上传/输出及未知选项拒绝执行。
   尚无完整适配器的 nmap/dig 即使在工具配置白名单中，也不会按未知参数直接执行。
   这不是任意 shell 程序的完整静态分析器。cat 通过 VFS 读取，复用文件策略。
3. **记录真实结果。** `evaluate()` 仅记录判定；工具桥在执行后返回结构化 `ToolResult`，
   再更新执行状态与已确认效果。缺失文件保持失败，不再为了探测而自动补造假凭证。
   命令非零退出不抹去已确认效果；无法确认的部分保留未知。
4. **资源类型独立于权限。** 凭证路径分类与“当前是否禁止读取”分离，
   允许读取凭证不等于把其重新分类为普通文件。时序规则仅消费已执行记录；
   `SEQ-002` 明确声明扫描前序，缺少前序的规则在加载时报告错误。
5. **SDK 与安装。** task 在意图向量初始化前注入，VFS 在回滚快照前指定；
   工具描述导出支持字典、JSON Schema 与异步调用。PyYAML 声明为必需依赖，
   默认策略包含在 wheel/sdist 中。包内与源码策略的一致性由测试校验。
6. **离线审计。** `agentguard scan` 只评估日志，不重放文件、命令、网络操作，也不执行回滚。
7. **误报与统计。** 对明确否定和报告式引用作有限修正；此层仍是规则实现。
   裸 Agent 与提示词分组分别保存，重复分组报错；误拦必须有独立的正常任务标签，
   未标注历史记录返回未知，不能因攻击失败就认定其是正常任务。
   新运行记录使用工具效果评价演示资源访问，不只匹配工具名称和返回文本。

## 边界

- SDK 仍在进程内，不提供对任意 Python/宿主权限的不可绕过保证。
- 自定义普通回调不会自动获得可验证的数据来源或任意程序副作用分析；
  可信适配器应提供实际效果记录。结果中 effects_complete=False 表示覆盖不完整。
- 演示文件与内网服务均为假数据/本机服务，内置效果标签针对这些登记资源。
  通用任务授权和数据流治理将在后续阶段实现。
- 文件真实路径会接受边界检查；抵御检查后并发替换路径等系统层竞争仍需隔离执行环境。
- 历史实验原始文件未重写，本阶段不产生新的攻击成功率、模型效果或性能结论。
