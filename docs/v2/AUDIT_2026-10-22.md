## 本轮发现并修复的问题

| 优先级 | 原问题及触发条件 | 修复 |
|---|---|---|
| 高 | 已读取的受限数据可写进 public 目录，新会话读文件会丢掉原限制 | WRITE 在执行前检查目标资源标签不得弱于输入标签；同时校验派生数据资源范围 |
| 高 | state_directory 放在工具工作目录下会把隔离库暴露给工具 | 应用配置和 Runtime 会话创建均拒绝资源根与私有存储重叠 |
| 高 | 工具已执行、HTTP 响应丢失或 checkpoint 未保存后，宿主重启可能重新规划并生成新调用 | 执行/最终交付前持久化阻止继续运行的状态；结束和轮数上限同样跨重启保留 |
| 高 | 工具标记 synthetic_demo 就可让结果在控制台显示，即使它回显真实输入 | 模型输出及工具结果按会话、工具和全部来源共同决定假数据标记；省略历史也不能去掉来源限制 |
| 中 | 恢复计划/确认已写入服务端但响应丢失，本地无法完成恢复 | 原子写入恢复请求/计划/Ack；相同绑定可重放，改变或已经过期的 Ack 拒绝 |
| 中 | 服务启动没有接管崩溃后的 CLAIMED/活动记录，恢复会一直等待 | CLI 生命周期持有跨进程 OS 锁；取得独占权后把遗留执行标记 UNKNOWN，禁止重复调度 |
| 中 | FastAPI 未预期异常虽然响应脱敏，仍会向外重抛并进入服务器异常日志 | 内层边界捕获并返回有限错误，测试启用 ASGI 异常传播以验证没有重抛；请求正文读取同时加实际大小上限 |
| 中 | `--gateway` 仍建立闲置本地 SQLite/隔离库；gateway extra 漏装 HTTP 客户端 | 注入远程 RuntimePort，不构建本地 Runtime；补充 httpx 声明 |
| 中 | 评测只读取前 1,000 条事件，会遗漏长任务后期恢复和释放 | 分页读取到最后一页再计算指标 |
| 中 | 读取缺失/过大文件被当成副作用 UNKNOWN；已知读失败也误触发恢复 | 可信只读工具标记 FAILED_KNOWN，实际字节读取有上限；已知无副作用失败提供有限反馈后可继续 |

这些修复没有放宽 Guard 失败时的释放条件，没有绕过主 Agent 的权限和最终输出门禁。
