本轮还补了公共 `HostInputRequest`、`register_host_input`/缓存清理宿主接口、可选模型用量、假数据会话标记及对应 JSON Schema。配置来自可信宿主；模型不能通过任务文字设置端点、导入工具代码或更改假数据标记。

关系上下文中的来源边保留当前对象附近的真实边，省略历史图的重复展开，完整 DAG 仍在 Runtime 中。源对象身份、所有数据限制和未决风险不随图裁剪消失；不把多跳 possible 路径伪造成 exact 边。这样长任务不会因反复展开全历史关系图而先耗尽审查预算。

功能与结果须分开理解：这些入口已经有实际执行路径；真实供应商连通性、模型语义质量、误拦率、费用、AgentDojo 环境安装与比赛全量实验仍按用户要求留到后续运行。外部样本导入不等于通过官方评测；脚本场景不等于模型能力。

LangChain 支持范围是一个明确的无隐藏状态 `BaseChatModel` 接入。关闭框架自动执行、回调、外部追踪和流式展示；本地 checkpoint/记忆归宿主管。任意现有 AgentExecutor、LangGraph 或带外部记忆的链不能直接声明支持完整恢复，必须提供对应重置钩子。

宿主恢复清理的是自身持有的状态和登记的工作文件。已有 WRITE/SEND/DELETE、已释放的最终输出、UNKNOWN 副作用继续保留在恢复计划中；不会因为 Ack 成功而被描述成已经撤销。
